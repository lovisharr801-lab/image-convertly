Frequently asked questions

Why would I need a PNG instead of the SVG?

Many platforms — social media, some CMS image fields, older software — don't accept SVG uploads, so a rendered PNG is more universally usable.

Will the PNG look exactly like the SVG?

Yes, at the size the SVG defines. If you need a larger PNG, scale the SVG's width/height before converting, since PNG is not resolution-independent like SVG.

Does it support animated SVGs?

No — this captures a single static frame of the SVG, not any embedded animation.

Is my file uploaded anywhere?

No, conversion happens locally in your browser.
